# Средство для припоминания

Мультимедийный лонгрид по мотивам встречи с Евгением Примаковым.
Авторы: Элена Мустафина, Марина Штукатурова.

## Что в папке

- `index.html` — сам лонгрид (11 экранов).
- `assets/css/style.css`, `assets/js/main.js` — стили и интерактив, без библиотек и сборки.
- `assets/img/` — фото с Wikimedia Commons (авторы и лицензии в подписях и в `sources.md`).
- `text.md` — текст лонгрида отдельным файлом.
- `sources.md` — каждый факт со ссылкой на источник.

Шрифты (Cormorant Garamond, Golos Text) подгружаются с Google Fonts, видео с YouTube. Для них нужен интернет.

## Как опубликовать на GitHub Pages (без командной строки)

1. Войдите на github.com, нажмите «+» → **New repository**. Имя, например, `longread`. Тип **Public**. Нажмите **Create repository**.
2. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
3. Перетащите в окно **содержимое** папки: `index.html`, папку `assets` (целиком), `README.md`, `text.md`, `sources.md`. Важно, чтобы `index.html` оказался в корне репозитория, а не внутри другой папки.
4. Внизу нажмите **Commit changes**.
5. Откройте **Settings** → **Pages**. В разделе **Build and deployment** выберите Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**. Нажмите **Save**.
6. Через 1–2 минуты сверху на той же странице появится ссылка вида `https://ВАШ-ЛОГИН.github.io/longread/`. Её и сдавайте.

## Как посмотреть локально

Если открыть `index.html` двойным щелчком, всё работает, кроме видео: YouTube не воспроизводится со страниц `file://`. Чтобы проверить видео, запустите в папке проекта локальный сервер:

```bash
python -m http.server 8765
```

и откройте http://localhost:8765.
