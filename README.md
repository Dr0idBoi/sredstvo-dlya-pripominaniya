# Средство для припоминания — версия 2

Мультимедийный лонгрид по мотивам встречи с Евгением Примаковым.
Авторы: Элена Мустафина, Марина Штукатурова.

Текст и факты те же, что в версии 1 (см. `text.md` и `sources.md`). Во второй версии изменилась подача: носитель информации меняется у читателя на глазах.

## Что происходит на странице

- **Обложка.** Заголовок собран из нескольких тысяч частиц. При загрузке они слетаются в буквы, курсор или касание их разгоняет, при прокрутке заголовок рассыпается в облако. В конце страницы он собирается снова.
- **«Проверьте себя».** Клавиатура телефона; после ответа цифры улетают вверх, а полоски с данными «Касперского» вырастают.
- **«Три перехода».** Закреплённая сцена: одна точка превращается в сетку копий, копии растворяются в облако.
- **Главная цитата** проявляется слово за словом по мере прокрутки.
- **Таймлайн** листается вбок при вертикальной прокрутке; фон меняется вместе с носителем: глина, пергамент, бумага, металл ЭВМ, экран, облако. На телефоне таймлайн вертикальный.
- **Платон.** Стела проявляется снизу, слова цитаты проступают из размытия.
- **MIT.** Счётчик 83% и график из квадратов (один квадрат — один участник).
- **Калькулятор.** Красное светодиодное табло показывает 1986, потом 79; рядом 6000 точек-делегатов, из них светятся 20 пикетчиков.
- **«Нет, не нравится».** Экран «загорается» из темноты, фразу «они уже пишут для нас» печатает машина.
- **Дуэль** «Чип» и «Голова» разъезжается навстречу.

Если в системе включено «уменьшение движения», анимации отключаются, а весь текст и графики остаются на месте.

## Файлы

- `index.html` — страница.
- `assets/css/style.css`, `assets/js/main.js`, `assets/js/particles.js` — стили, сцены, частицы.
- `assets/vendor/` — GSAP 3.12.5, ScrollTrigger 3.12.5, Lenis 1.1.13 (скачаны локально, интернет для них не нужен).
- `assets/img/` — фото с Wikimedia Commons, авторы и лицензии в подписях.

Шрифты подгружаются с Google Fonts, видео с YouTube.

## Публикация на GitHub Pages

1. github.com → «+» → **New repository**, тип **Public**, **Create repository**.
2. Ссылка **uploading an existing file** → перетащите **содержимое** этой папки (`index.html`, папку `assets` целиком, `README.md`, `text.md`, `sources.md`). `index.html` должен оказаться в корне репозитория.
3. **Commit changes**.
4. **Settings** → **Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты появится ссылка вида `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Чтобы выложить обе версии в одном репозитории, загрузите папки `v1` и `v2` целиком: сайт будет открываться по адресам `.../v1/` и `.../v2/`.

## Локальный просмотр

Двойной щелчок по `index.html` работает, но видео YouTube со страниц `file://` не воспроизводится. Для полной проверки:

```bash
python -m http.server 8765
```

и откройте http://localhost:8765.
